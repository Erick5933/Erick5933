## About

I started programming in 2023 — initially self-taught with Java, then learning alongside a team how to design systems that could actually scale. What began as writing classes became designing APIs, then deploying infrastructure, then integrating AI into products that real businesses depend on.

In two years I went from printing "Hello World" to shipping a multi-tenant SaaS platform in production. Not because I'm exceptional — because I take problems seriously and I don't stop until the system works.

Before code, I worked with precision tools in my family's goldsmithing workshop. That background taught me something that stayed: **the quality of craftsmanship is visible whether anyone is looking or not.** I try to write software the same way.

---

## Build philosophy

```
  01  Systems over features.
      A feature solves today's problem. A well-designed system
      solves the next ten problems you haven't thought of yet.

  02  Clarity is a technical requirement.
      Code that a teammate can read at 2 AM without context
      is not a luxury — it's part of the job.

  03  Ship, then improve.
      A working system in production teaches you more than
      a perfect system that lives in a branch.

  04  Understand the business, not just the spec.
      The best technical decisions come from knowing why
      something needs to exist, not just what it should do.
```
